전문 요약

공공 안전·환경 관제 분야에서 통합 플랫폼 구축, 실시간 통신, 외부 API·DB 연계, 운영 자동화와 장애 안정화를 수행했습니다. 이전에는 글로벌 게임 서버와 웹 백엔드를 개발하며 최대 13만 동시접속 규모의 라이브 서비스를 운영했고, AWS·Docker·Redis·Nginx 기반 인프라와 성능 최적화를 경험했습니다. 2024년 현장 장비 DB 구축과 웹·서버 보안, Git 기반 운영 표준화를 시작으로 2025년 철원 통합관제플랫폼, 남구미 LPR-DID, IDC 예경보방송과 제주 관측데이터 연계를 개발했습니다.

개발 방식

다양한 플랫폼·운영체제·언어·DB 환경에서 서버와 웹 서비스를 개발하고 디버깅해왔습니다. 로컬 또는 격리 환경에서 동작을 재현하고 로그·덤프·성능 지표를 바탕으로 원인을 좁힌 뒤, 코드 리뷰와 테스트를 통해 출시 이후까지 안정성을 확인하는 방식으로 일합니다. 클라이언트·기획·현장 담당자와 요구사항을 조율하며 서비스 운영에 필요한 인프라까지 직접 연결합니다.
